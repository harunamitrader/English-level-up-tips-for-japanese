## はじめに

英語ができると何が変わるか？

- 新しい技術情報をいち早く英語で得られる
- Stack Overflow・GitHub Issues・公式ドキュメントが読みやすくなる
- 海外カンファレンスの発表や動画が理解できる
- 世界中のエンジニアと対等にコミュニケーションできる

学習効率を劇的に高める方法があります。このガイドがそのきっかけになれば幸いです。

## 英語レベルの目安（CEFR）

| レベル | 目安 |
|---|---|
| A1 / A2 | 初級。基本的な表現が使える |
| B1 / B2 | 中級。日常会話・技術文書がだいたい読める |
| C1 / C2 | 上級。ネイティブとほぼ対等に話し書ける |

日本のエンジニアが最初に目指すべきは **B1〜B2** です。TOEIC 700〜800 点台がその目安になります。
