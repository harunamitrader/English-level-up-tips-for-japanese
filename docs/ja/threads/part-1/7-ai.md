# 第7章：AI活用篇

AI ツールは英語学習を大幅に効率化します。2024年以降、活用しない理由がありません。

## ChatGPT・Claude を英語学習に使う

### 会話練習

「英語で会話相手になってください」と頼むだけで、24時間いつでも練習相手になってくれます。

プロンプト例：
```
Please have a casual conversation with me in English. 
Correct my grammar mistakes and suggest more natural expressions when I make errors.
Topic: Let's talk about your latest side project.
```

### 添削・改善提案

自分が書いた英文を貼り付けて、改善点を聞けます。

```
Please review the following English text and:
1. Fix any grammar mistakes
2. Suggest more natural expressions
3. Point out any unnatural phrasing

[ここに自分の英文]
```

### 語彙・表現の質問

```
What's the difference between "affect" and "effect"?
Can you give me 5 example sentences using "leverage" in a tech context?
```

### 学習計画の作成

```
I'm a Japanese software engineer with TOEIC 600. 
My goal is to read English technical documentation comfortably in 3 months.
Please create a realistic daily study plan for me.
```

## AI を使ったシャドーイング練習

YouTube 動画の自動字幕（英語）をコピーして AI に貼り付け、発音のコツや重要表現を解説してもらう使い方もできます。

---

## AI の限界を知っておく

- 発音の指導は苦手（音声入出力が必要）
- 感情的なフィードバックやモチベーション維持には向かない
- 最新スラングや超口語表現は不正確な場合がある

AI はあくまで**補助ツール**です。実際の会話相手・良質なコンテンツのインプットと組み合わせて使うのが最も効果的です。

---

## おすすめの AI 英語学習フロー

1. 今日学びたいテーマを決める（例：「リモートワークの pros and cons を英語で話せるようにする」）
2. ChatGPT / Claude に関連語彙・表現を10個リストアップさせる
3. それを使った例文を作らせる
4. 自分でもその表現を使って会話練習する
5. 自分が書いた文章を AI に添削させる

このサイクルを毎日30分続けるだけで、3ヶ月後には確実に変化を感じられます。
