# 第1章：認知篇 ─ 学ぶ前に知っておくこと

本章では、英語学習を始める前に整理しておきたい「考え方」について話します。

## なぜ英語を学ぶのか

英語はインターネット上のコンテンツの約6割を占める言語です。  
特に IT 分野では、新しい技術・ライブラリ・フレームワークの情報はほぼすべて英語で最初に公開されます。

英語ができると：

- 公式ドキュメントをそのまま読める
- GitHub Issues・Stack Overflow で検索精度が上がる
- 英語の技術書・論文・カンファレンス動画を直接消化できる
- 翻訳品質のバラつきに振り回されなくなる

## 学習ピラミッド理論

アメリカの研究者 Edgar Dale が提唱した「学習ピラミッド（The Cone of Learning）」によると、学習直後の定着率はこうなっています。

| 学習方法 | 定着率の目安 |
|---|---|
| 読む | 10% |
| 聴く | 20% |
| 図解・映像で見る | 30〜50% |
| 議論・説明する | 70% |
| 実際にやってみる | 90% |

語学学習においても同じです。読むだけ・聴くだけの受動的な学習より、**声に出す・書く・使う**という能動的な関与が定着率を大きく高めます。

## 効率が上がらない人に共通する5つのパターン

### 1. 動機が「義務」になっている

「TOEIC のスコアを上げなければ」「昇進条件だから」という外発的動機だけで学んでいる場合、学習はすぐ苦行になります。  
**英語そのものに少しでも興味を持てる入口**（好きな音楽、ゲーム、技術分野）から入るほうが長続きします。

### 2. レベルに合わない素材を使っている

知らない単語が10語に5語以上出てくる素材は難しすぎます。  
**知らない単語が10語に1〜2語程度**の素材を選ぶのが、インプット効率のよい領域です（Krashen の Input Hypothesis）。

### 3. 字幕・日本語訳に依存している

英語字幕・日本語字幕を常に表示して視聴していると「読めている」錯覚が生まれます。  
字幕なしで聞き取れるか、定期的に確認することが重要です。

### 4. 睡眠を削って学習している

睡眠不足は記憶の定着を阻害します。深夜の詰め込み学習で得たものは、翌朝には消えている可能性があります。  
**質の高い睡眠と適切な休息**が、学習効率を最大化する最も地味で最も重要な要素です。

### 5. 学習計画がない

「毎日なんとなくアプリをやっている」では、苦手部分が放置されます。  
自分が何を目標にしていて（TOEIC・英語面接・技術文書読解など）、どのスキルが弱いかを分析したうえで計画を立てましょう。

## 自分の学習シーンを明確にする

以下から自分に当てはまるものを絞り込んでください。目標が違えば、最適な学習法も変わります。

| 目的 | 重点スキル |
|---|---|
| 資格試験（TOEIC・英検・IELTS） | リーディング・リスニング |
| 技術文書を読む | リーディング・語彙 |
| 海外カンファレンス・発表 | リスニング・スピーキング |
| 外国人エンジニアとの日常会話 | スピーキング・リスニング |
| 英語でブログ・OSS コメントを書く | ライティング・語彙 |

## 日常に英語を溶け込ませる

特別な「勉強時間」を作るより、日常の習慣を英語に置き換えるほうが継続しやすいです。

- YouTube で技術系チャンネルを英語で視聴する
- Slack・GitHub のコメントをまず英語で書いてみる
- スマートフォンの言語設定を英語にする
- 通勤中にポッドキャストを英語で聴く

> Make English a part of your daily life.  
> 英語を、歯を磨くような習慣にしてしまいましょう。

## 子どもが言語を習得する方法から学ぶ

幼児が母国語を習得する過程を観察すると、興味深いことがわかります。

- 完璧な文法より先に「意味の通じる塊」を口にする
- 間違えても笑われない安全な環境がある
- とにかく量をこなす（聴く・しゃべる）

英語学習でも同じです。  
**完璧な文法より先に「伝わること」を優先し、間違いを恐れずに量をこなす**。  
この順番を守るだけで、多くの人は今より格段に速く伸びます。
