# 第5章：スピーキング篇

## まず発音の基礎を作る

スピーキングの出発点は**正しい発音**です。単語を間違った発音で覚えると、聴き取りにも悪影響が出ます。

### 日本人が特に注意すべき発音

| 音 | 難しい理由 | 練習のポイント |
|---|---|---|
| L / R | 日本語に区別がない | L は舌先を上歯茎につける。R は舌を浮かせて後ろへ引く |
| V / B | 日本語では同じ「バ行」 | V は上歯を下唇に当てて摩擦音を出す |
| TH (θ / ð) | 日本語に存在しない | 舌先を上下の歯の間に挟んで息を出す |
| 語末の子音 | 日本語は母音で終わる傾向がある | `cat` は「キャット」でなく `t` で止める |
| 強勢（ストレス） | 日本語は音節が等拍 | 英語は強拍・弱拍の差が大きい |

## 大声で読む・シャドーイング

スピーキング力は「声を出す量」に正比例します。

**練習の流れ**：

1. 素材（ドラマ・TED・教材）を集中して聴く
2. スクリプトを見ながら、まず一語一語正確に発音する
3. 音声と同時に声を出す（シャドーイング）
4. 慣れてきたら連結・抑揚・リズムも真似る

最初から流暢に話そうとする必要はありません。**まず個々の発音を正確に**、次に滑らかさを追求します。

---

## 「頭の中で翻訳する」を卒業する

多くの日本人は英語で話すとき、以下のような処理をしています。

```
日本語で考える → 英語に翻訳する → 口に出す
```

これでは会話が追いつきません。ある単語・表現が「自動的に口から出る」状態（言語の反射）に持ち込むには、**大量のアウトプット練習**が必要です。

「fuck」「seriously?」「That makes sense.」など、感情に直結する言葉ほど自動化しやすいです。日常的に声に出し続けることで、徐々に反射の回路が育ちます。

---

## 定型トピックを準備しておく

会話の場面で焦らないために、よく使うトピックをあらかじめ準備して繰り返し練習しておきます。

- 自己紹介（名前・職業・スキル）
- 今取り組んでいるプロジェクト
- 出身地・住んでいる都市
- 好きな技術・趣味
- 最近読んだ本・観た映画

完璧な文法より、**スムーズに言えること**を優先します。

---

## 英語の歌を歌う

楽しいことは続きます。好きなアーティストの曲を使って発音・リズム・イントネーションを練習できます。

**手順**：
1. 好きな曲の歌詞を調べる
2. 知らない単語を先に覚える
3. 何度も一緒に歌う

音楽は感情と結びつくため、言葉の定着率が高いです。

## 外国人と実際に話す機会を作る

オンライン英会話・言語交換アプリを活用すると、実際に会話する機会を作れます。

- [italki](https://www.italki.com/) ─ プロ講師・ネイティブとのマンツーマンレッスン
- [HelloTalk](https://www.hellotalk.com/) ─ 言語交換アプリ（相手の言語を教え合う）
- [Tandem](https://www.tandem.net/) ─ 言語交換。チャット・音声・ビデオ対応

初めて外国人と話すときの「あわあわ感」は誰でも同じです。失敗を恐れず、**まず話し始める**ことが唯一の突破口です。
